# 🚀 Zynk Menu

Menu customizado para Roblox com animações suaves, monitoramento em tempo real (FPS, Ping e Jogadores) e correções de interface.

## 📜 Como Usar

Cole o código abaixo em um `LocalScript` ou no seu executor:

\`\`\`lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/SEU_USUARIO/NOME_DO_REPO/main/Main.lua"))()
\`\`\`

## ✨ Funcionalidades
- 📊 **Página de Status:** Exibe FPS, Ping (ms) e quantidade de jogadores no servidor.
- 🎨 **Animações Suaves:** Transições com `TweenService` entre abas e ao minimizar/fechar.
- 🛡️ **Interação Segura:** `Active = true` e `Modal = true` para não interferir no jogo.
